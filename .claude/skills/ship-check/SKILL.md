# Purpose

Use this skill before final submission, after deployment and E2E evidence are in place.

## Audit Focus

Check whether the repository clearly proves:

1. the feature works end-to-end
2. the workflow was Spec-Kit-driven
3. AI usage was structured and documented
4. E2E automation is real and reproducible
5. video and trace artifacts are easy to find
6. README is clear and honest
7. the repo reads like a focused product build, not a framework showcase

## Missing Submission Artifacts

- ...

- ...

## Final Readiness

- READY or NOT READY
- short justification

## Rules

- be skeptical
- optimize for reviewer trust
- call out missing or confusing evidence explicitly
- do not suggest large refactors at this stage unless correctness is at risk
