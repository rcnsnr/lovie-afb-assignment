# AI Process Sync

## Purpose

Use this skill to keep `docs/AI_PROCESS.md` current.

Use it after:

- a completed Spec-Kit phase
- a meaningful implementation slice
- a review or audit pass
- a major validation milestone
- a deployment or evidence milestone
- a moment where AI output had to be corrected or constrained by human judgment

---

## Operating Rules

1. Update the existing file instead of replacing it.
2. Keep entries concrete and reviewer-friendly.
3. Record actual tools, prompts, and corrections only.
4. Do not exaggerate AI contribution.
5. Explicitly note where human judgment changed direction or corrected output.
6. Keep examples short.

---

## Required Updates

When relevant, update these sections:

- `Tools Used`
- `Representative Prompt Patterns`
- `Where AI Helped`
- `Where AI Was Weak`
- `Manual Corrections`
- `Notes for Reviewers`
